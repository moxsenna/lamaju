# Portfolio Landing Page UMKM — 4 Variasi UI

Isi proyek:

- `rental-mobil.html` — dark utility, fleet filter, CTA ketersediaan.
- `pet-grooming.html` — playful rounded, selector kucing/anjing, paket dinamis.
- `wedding-organizer.html` — editorial luxury, mood switcher, timeline dan paket.
- `frozen-food.html` — bold commerce, filter produk, quantity control, mini cart WhatsApp.
- `index.html` — galeri untuk membuka seluruh contoh.

Semua landing page adalah **standalone single-file HTML**. CSS, JavaScript, dan ilustrasi SVG berada di dalam masing-masing file.

## Mengatur nomor WhatsApp

Cari konstanta berikut di bagian akhir setiap HTML:

```js
const WA_NUMBER = '6281234567890';
```

Ganti dengan nomor WhatsApp bisnis dalam format internasional tanpa tanda `+`, spasi, atau tanda hubung.

Contoh:

```js
const WA_NUMBER = '628123456789';
```

Selama nomor masih berupa placeholder, tombol akan menampilkan pemberitahuan dan tidak membuka nomor acak.

## Catatan portfolio

Seluruh merek, harga, paket, angka, kebijakan, dan hasil yang ditampilkan bersifat fiktif untuk demonstrasi. Sesuaikan seluruh data dengan brief dan bukti klien sebelum dipublikasikan.
