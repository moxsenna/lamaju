# QA Report

Empat halaman diuji pada Chromium headless.

## Viewport

- 1440 × 900
- 390 × 844
- 320 × 568

## Hasil umum

- Satu `h1` per halaman.
- Tidak ada horizontal overflow pada 320, 390, dan 1440 px.
- Tidak ada JavaScript page error atau console error.
- Menu mobile berfungsi.
- FAQ accordion berfungsi.
- CTA WhatsApp memiliki proteksi nomor placeholder.

## Interaksi khusus

### Rental Mobil

- Filter kategori armada berfungsi.
- Tombol unit menyusun pesan WhatsApp berdasarkan mobil.
- Filter `Keluarga` hanya menampilkan armada yang sesuai.

### Pet Grooming

- Selector Kucing/Anjing berfungsi.
- Contoh harga berubah sesuai jenis hewan.
- Tombol paket menyusun pesan kontekstual.

### Wedding Organizer

- Switcher Garden, Modern, dan Tradisional berfungsi.
- Judul serta deskripsi mood berubah.
- Tombol paket membawa nama paket ke pesan WhatsApp.

### Frozen Food

- Filter kategori produk berfungsi.
- Tombol tambah/kurang jumlah berfungsi.
- Total dan jumlah item diperbarui otomatis.
- Ringkasan order disusun untuk WhatsApp.
